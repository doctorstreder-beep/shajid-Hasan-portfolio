# Md. Shajid Hasan — Professional Portfolio

Modern single-page portfolio website for Civil Engineering student.

## How to use (GitHub Pages)

1. Create a new GitHub repository (e.g. `shajid-portfolio` or `username.github.io`)
2. Upload the `index.html` file (or the whole folder) to the repository
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)` folder
5. Save — your site will be live at:  
   `https://your-username.github.io/repository-name/`

## Features

- Clean modern design inspired by professional engineering portfolios
- Light / Dark theme toggle
- Fully responsive (mobile + desktop)
- Sections: About, Skills, Projects, Experience, Leadership, Education, Contact
- Fast loading — pure HTML + CSS + minimal JS

## Customization

Open `index.html` and edit the text, links, or colors as needed.
You can change the primary color by editing the CSS variables `--blueprint` and `--accent`.
